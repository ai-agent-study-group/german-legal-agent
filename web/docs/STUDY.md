## 주제 후보: 질문과 역할

judgenote를 참고 사례로 소개합니다. 현재 프로젝트를 실행하고 데모 표시를 확인합니다.
개발자는 선택한 모델에 단순 질문을 보내는 어댑터를 연결합니다. 처음에는 도구 없이 답변만 받습니다.
비개발자는 같은 질문을 기본 역할/주거 역할로 비교하고, 어떤 설명이 확인 가능한지 기록합니다.
학습 결과 예시: 모델에 전달하는 질문과 담당 규칙을 설명할 수 있습니다.
데모의 역할 문구는 모델처럼 답변을 바꾸지 않는다는 점을 먼저 알려주세요.

## 주제 후보: 준비된 자료

collect.py를 실행해 원문과 pending을 비교합니다. 실패하면 기본 예제 자료로 계속합니다.
searchSources를 AI 없이 실행해 한국어 키워드와 검색 결과를 확인합니다.
코드가 매번 검색한 자료를 모델에 전달하는 챗봇을 만듭니다.
학습 결과 예시: 자료가 없는 답변과 자료가 있는 답변을 비교하고 출처를 검증합니다.

## 주제 후보: 행동을 선택하는 모델

모델에 search_sources와 read_source를 제공하고 함수 호출 요청을 runAgent에 연결합니다.
모델→도구 요청→서버 실행→모델에 결과 전달→답변 흐름을 설명합니다.
짝별로 어떤 정보가 부족할 때 되물어야 하는지 규칙을 작성합니다.
학습 결과 예시: 검색이 필요한 질문과 되물어야 하는 질문에서 동작을 관찰합니다.
현재 데모는 같은 흐름을 규칙으로 재현할 뿐, 모델 판단을 검증하지 않습니다.

## 주제 후보: 실패 원인

다른 짝이 작성한 질문으로 테스트합니다. 자료 부족 / 검색 실패 / 설명 오류 / 맥락 오류를 구분합니다.
선정한 실패 사례를 수정하고 동일한 질문의 결과를 비교합니다.
학습 결과 예시: 정상 검색·추가 질문·근거 부족 각 한 사례를 시연하고 왜 그렇게 동작했는지 설명합니다.

## 쉬운 용어

- API: 프로그램끼리 요청과 결과를 주고받는 연결 방식.
- 스크래핑: 웹페이지에서 필요한 내용을 가져오는 작업.
- 도구: AI가 실행을 요청할 수 있도록 만든 함수.
- 실행 루프: 요청을 실행하고 결과를 돌려주는 과정을 반복하는 코드.
- 어댑터: 서로 다른 모델의 요청 형식을 공통 형식과 연결하는 코드.
