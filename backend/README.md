# 백엔드 논의 공간

현재 Python 3.12 기반 FastAPI 앱과 API 테스트가 있습니다. 별도의 Next.js 데모도 `web/`에 있으며, 두 실행 단위의 최종 연동·배포 구조는 논의 중입니다.

## 로컬 테스트

Python 3.12와 [uv](https://docs.astral.sh/uv/)를 준비하고 이 폴더에서 실행합니다.

```bash
uv sync --locked
uv run --locked pytest
```

CI도 같은 명령으로 백엔드 API 테스트를 실행합니다. 현재 별도 백엔드 린트 검사는 설정되어 있지 않습니다. 테스트는 테스트용 토큰을 사용하며 실제 API 키가 필요하지 않습니다.

다룰 수 있는 역할: 질문 API, agent 실행, 검색·읽기 도구, 자료 저장소 접근.
최종 위치는 Next.js 내부 유지 / 별도 백엔드 / 공통 패키지 등 선택에 따라 달라질 수 있습니다.
