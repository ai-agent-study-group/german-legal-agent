# 자료 수집·정리 논의 공간

상태: **범위·언어·내부 구조 미정**. 현재는 문서만 있습니다.
기존 Python 수집·검토 승인 데모는 `web/scripts/scrape/`에 있으며 자료는 `web/data/`에 있습니다.

다룰 수 있는 역할: 공식 출처 조사, API·파일·웹 본문 수집, 분류·중복 확인, 검토·갱신.
백엔드와 같은 언어를 써야 하는 것은 아닙니다. 수집 실행과 사용자 질문 응답의 실행 방식도 따로 논의할 수 있습니다.
