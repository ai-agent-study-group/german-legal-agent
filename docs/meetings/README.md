# 회의 기록

날짜별로 안건, 논의 메모, 결정 사항, 할 일, 미결 사항을 정리합니다.

**정기 모임: 매주 목요일 18:00 (Europe/Berlin).**

| 날짜 | 회의 | 상태 |
| --- | --- | --- |
| [2026-10-15](2026-10-15.md) | 킥오프 | 안건 · 공유된 역할 배정 반영 |

새 회의는 `TEMPLATE.md`를 복사해 `YYYY-MM-DD.md`로 만들고 위 목록에 추가합니다.
같은 날 여러 회의가 있으면 `YYYY-MM-DD-02.md`처럼 구분할 수 있습니다.

- 회의 전: 날짜·안건을 작성하고 모르는 내용은 빈칸이나 `?`로 둡니다.
- 회의 중: 의견·후보는 논의 메모에, 합의한 내용은 결정 사항에 기록합니다.
- 회의 후: 할 일의 담당·기한을 확인하고 미결 사항을 다음 회의로 연결합니다.

회의 폴더도 메뉴에서 접고 펼칠 수 있습니다. Markdown 회의록은 변경 검토 요청(Pull Request, PR) 없이 직접 저장할 수 있습니다. 이는 다른 사람에게 먼저 내용을 확인받고 기본 브랜치에 합쳐달라고 요청하는 절차이며 문서만 바꾸면 선택 사항입니다.
