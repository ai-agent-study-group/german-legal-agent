# 회의 기록

날짜별로 안건, 논의 메모, 결정 사항, 할 일, 미결 사항을 정리합니다.

**정기 모임: 매주 목요일 18:00 (Europe/Berlin).**

| 날짜 | 회의 | 상태 |
| --- | --- | --- |
| [2026-10-15](2026-10-15.md) | 킥오프 | 회의 전 · 안건 준비 |

새 회의는 [템플릿](TEMPLATE.md)을 복사해 `YYYY-MM-DD.md`로 만들고 위 목록에 추가합니다.
같은 날 여러 회의가 있으면 `YYYY-MM-DD-02.md`처럼 구분할 수 있습니다.

- 회의 전: 날짜·안건을 작성하고 모르는 내용은 빈칸이나 `?`로 둡니다.
- 회의 중: 의견·후보는 논의 메모에, 합의한 내용은 결정 사항에 기록합니다.
- 회의 후: 할 일의 담당·기한을 확인하고 미결 사항을 다음 회의로 연결합니다.
- 프로젝트 전반에 영향을 주는 합의는 [프로젝트 논의 항목](../PROJECT_PLAN.md)과 [팀 문서](../TEAM.md)에도 회의록 링크와 함께 반영합니다.
