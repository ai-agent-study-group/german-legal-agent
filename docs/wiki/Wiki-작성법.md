# Wiki 작성법

이 위키는 GitHub Wiki로 운영합니다. 웹에서 바로 고치거나, 로컬에 clone해 여러 문서를 한 번에 작업할 수 있습니다. PR은 없고 저장하면 바로 반영됩니다.

> ⚠️ **페이지를 추가하거나 삭제하면 반드시 `_Sidebar`(목차)도 같이 고쳐야 합니다.**
> GitHub Wiki는 새 페이지를 자동으로 목차에 넣어 주지 않습니다. `_Sidebar`를 안 고치면 페이지는 만들어져도 오른쪽 목차에 안 보이고, 삭제한 페이지는 목차에 깨진 링크로 남습니다.

## 웹에서 수정

1. 페이지 오른쪽 위 **Edit**를 누릅니다.
2. Markdown으로 작성하고 **Save Page**를 누릅니다.
3. 새 문서는 오른쪽 위 **New Page**로 만듭니다.
4. **페이지를 새로 만들거나 지웠으면 바로 아래 "사이드바(목차) 수정"대로 `_Sidebar`도 고칩니다.**

## 사이드바(목차) 수정

**페이지 추가·삭제 시 필수 단계입니다.** 오른쪽 목차는 위키 저장소의 `_Sidebar` 페이지 하나로 관리됩니다.

1. 위키에서 `_Sidebar`를 열고 **Edit**를 누릅니다. (주소 끝에 `/_edit`을 붙여도 됩니다: `.../wiki/_Sidebar/_edit`)
2. 새 페이지는 해당 **직군 아래에** 링크를 추가합니다. 지운 페이지는 그 줄을 삭제합니다.
3. 링크는 `[페이지 제목](#doc=wiki/페이지-제목.md)` 형식입니다. 제목의 띄어쓰기는 파일 이름에서 `-`로 바뀝니다. 예: `[구조 BE](#doc=wiki/구조-BE.md)` → 파일 `구조-BE.md`.
4. **Save Page**를 누르면 목차에 바로 반영됩니다.

## 로컬에서 작업 (여러 문서 한 번에)

여러 문서를 한꺼번에 고칠 때는 위키 저장소를 clone해서 작업합니다.

```
git clone https://github.com/ai-agent-study-group/german-legal-agent.wiki.git
```

- 파일 이름은 `페이지 제목.md`이며 띄어쓰기는 `-`로 씁니다.
- 수정 후 아래로 올립니다. master에 바로 반영됩니다.

```
git add .
git commit -m "docs: update wiki"
git push origin master
```

## 문서 사이트에 잘 나오게 하려면 (꼭 읽어주세요)

여기 위키에 쓴 글은 **우리 문서 사이트(블로그처럼 생긴 화면)에도 자동으로 똑같이 올라갑니다.** 위키가 원본이고, 저장하면 보통 1~2분 뒤 사이트에 반영됩니다. 사이트에서 글이 예쁘게·제대로 나오게 하려면 아래 몇 가지만 지켜주세요. 어렵지 않습니다.

- **글 맨 위에 제목을 `#` 한 개로 한 줄 넣어주세요.** 예: `# 우리 팀 소개`. 이 제목이 사이트 목록에 그대로 쓰입니다. 안 넣으면 파일 이름이 제목으로 나와서 보기 안 좋습니다.

- **다른 위키 페이지로 연결할 때는 `[페이지 제목](#doc=wiki/페이지-제목.md)` 형식만 쓰세요.** 예: `[역할](#doc=wiki/역할.md)`. 이렇게 쓰면 사이트에서도 링크가 잘 동작합니다.

- **바깥 사이트(구글, 유튜브 등)로 연결할 때는 `https://`로 시작하는 전체 주소를 꼭 붙이세요.** 예: `[구글](https://google.com)`. `https://` 없이 주소만 쓰면 사이트가 "우리 위키 페이지"로 착각해서 링크가 깨집니다.

- **이미지는 위 "이미지" 안내대로 `assets/`에 넣거나, `https://`로 시작하는 전체 주소를 쓰세요.** 그냥 복사해 붙인 이미지는 사이트에서 안 보일 수 있습니다.

- **맨 윗줄에 `---` 를 넣지 마세요.** (특별한 설정으로 인식돼 제목이 깨집니다.)

### 이름을 바꾸거나 새 페이지를 만들 때

- **이미 있는 주요 페이지(`역할`, `구조-FE`, `구조-BE`, `회의록 양식` 등)의 제목은 바꾸지 마세요.** 이름을 바꾸면 사이트에서 그 글이 **사라지거나 엉뚱한 곳**에 생깁니다. 내용만 고치는 건 괜찮습니다.

- **새 페이지를 만들면 사이트의 "추가 문서" 칸에 들어갑니다.** 특정 직군 폴더(예: 프론트엔드, 백엔드) 안에 넣고 싶으면 **혼자 하지 말고 운영/개발 담당에게 말해주세요.** (코드 한 줄을 같이 고쳐야 합니다.)

- **위키에서 페이지를 지우면 사이트에서도 같이 사라집니다.** 실수로 지우지 않게 주의하세요.

## 이미지

- `assets/` 폴더에 넣고 `![설명](assets/경로)`로 참조합니다.
- SVG는 raw GitHub에서 렌더되지 않으므로 반드시 위키 저장소의 `assets/`에 함께 올립니다.

## 회의록

- 제목은 `YYYY-MM-DD 회의` 형식입니다. 파일은 `YYYY-MM-DD-회의.md`.
- [회의록 양식](#doc=wiki/회의록-양식.md)을 복사해 작성하고 [회의기록](#doc=wiki/회의기록.md) 목록과 사이드바에 추가합니다.
